# Contributing

## Guidelines

1. **Fork the Repository**: Start by forking the repository to your own GitHub account.
2. **Clone Your Fork**: Clone your forked repository to your local machine.
   ```bash
   git clone https://github.com/your-username/repository.git
   ```
3. **Create a New Branch**: Create a new branch for your feature or bug fix.
   ```bash
   git checkout -b feature/my-feature
   ```
4. **Make Changes**: Make the necessary changes to the codebase.
5. **Commit Your Changes**: Commit your changes with a descriptive message.
   ```bash
   git commit -m "Add my feature"
   ```
6. **Push Your Changes**: Push your changes to your forked repository.
   ```bash
   git push origin feature/my-feature
   ```
7. **Create a Pull Request**: Create a pull request from your forked repository to the original repository.

## Workflow

1. **Review Code**: The maintainers will review your code and provide feedback.
2. **Address Feedback**: Address any feedback or issues raised during the review process.
3. **Merge Pull Request**: Once your changes are approved, they will be merged into the main branch.

By following these guidelines and workflow steps, you can contribute effectively to the AI Event Platform project.
